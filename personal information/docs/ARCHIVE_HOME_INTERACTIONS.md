# 个人档案主页交互说明

## 档案袋

父组件 `ArchiveFolders` 统一保存当前打开的档案袋 ID。同一时间只能打开一个；点击另一个档案袋会自动关闭前一个。

点击后依次表现为绕线淡出、翻盖向后翻开、内部文件上移。再次点击时反向执行。动画集中在 `archiveFolders.module.css`。

## 学生证

第三个硕士档案袋打开后显示学生证。点击学生证使用 CSS 3D 旋转查看背面，再次点击返回正面。

## 纸片与报纸

纸片悬停时轻微回正、放大并加深阴影。点击后由 `PaperDetailModal` 展示完整 HTML 内容。关闭按钮、点击遮罩或按 Esc 均可关闭。

## 明信片

线索墙上的明信片点击后进入详情。在详情中点击明信片可进行正反面 3D 翻转。

## 灯光

`useLightingMode.ts` 统一维护开关状态并保存到 localStorage。

- OFF：画面压暗，CSS mask 手电筒跟随鼠标。鼠标移动只更新 CSS 变量，不触发 React 整页重渲染。
- ON：灯泡与环境光亮起，手电筒蒙版隐藏，开关显示 ON。

## 红线

红线由 `RedStringLayer.tsx` 根据 `clueConnections.ts` 绘制为 SVG。

悬停或聚焦纸片时，与该纸片相连的线条变亮，其余线条降低透明度；打开详情后，对应连接保持高亮。SVG 图层不响应指针事件。

## 无障碍与动效

档案袋、纸片、开关、学生证和明信片均使用原生按钮并支持键盘焦点。弹窗支持 Esc。所有主要动画均响应 `prefers-reduced-motion`。
